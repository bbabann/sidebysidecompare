# sidebysidecompare

A lightweight prototype for comparing two images side by side, or with an overlay slider.

## Run

No build step. Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Files

- `index.html` — markup
- `style.css` — layout and theme (light/dark)
- `script.js` — mode toggle, slider, image loading
